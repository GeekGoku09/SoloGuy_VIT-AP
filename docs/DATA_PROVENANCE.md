# DATA PROVENANCE AND LICENSING

## 1. CGMacros
- **Source URL:** https://physionet.org/content/cgmacros/
- **Licence:** Open Data Commons Attribution License (ODC-By) v1.0 / PhysioNet Restricted License
- **Access Level:** Open / PhysioNet Credentialed
- **De-identification Status:** Fully anonymized under HIPAA Safe Harbor.
- **Usage:** Headline training and evaluation set for multi-stream fusion model.
- **Citation:** PhysioNet CGMacros Dataset (2023).

## 2. BIG IDEAs
- **Source URL:** https://physionet.org/content/big-ideas/
- **Licence:** Open Data Commons Attribution License (ODC-By) v1.0
- **Access Level:** Open
- **De-identification Status:** De-identified time series and clinical parameters.
- **Usage:** External validation set for cross-cohort domain shift evaluation.
- **Citation:** PhysioNet BIG IDEAs Glycemic Dataset (2022).

## 3. ShanghaiT2DM
- **Source URL:** https://www.nature.com/articles/s41597-023-01940-7
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Access Level:** Open
- **De-identification Status:** Anonymized clinical and continuous glucose monitor data.
- **Usage:** T2D-specific cohort check.
- **Citation:** Scientific Data ShanghaiT2DM Dataset (2023).
